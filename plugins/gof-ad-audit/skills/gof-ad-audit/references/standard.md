## D 和游戏对得上

D1 熔炉和战力（必改）。只用下面的数，表外的天数和等级别自己估。熔炉最高 30 级。没说是付费玩家的，战力不写过亿。〔主〕熔炉战力表「广告宣传」列，〔群〕〔用〕

| 玩家 | 天数 | 熔炉 | 战力 |
|---|---|---|---|
| 不付费（开服天数） | 3 | 15 | 300 万 |
| | 7 | 18 | 600 万 |
| | 10 | 20 | 800 万 |
| | 15 | 22 | 1000 万 |
| | 30 | 25 | 2000 万 |
| | 45 | 28 | 3000 万 |
| | 57 | 30 | 5000 万 |
| 付费（注册天数） | 3 | 30 | 6000 万 |
| | 7 | 30 | 1 亿 |
| | 10 | 30 | 1.3 亿 |

只写等级、不写天数（注册 180 天内）：15 级 250 万，20 级 600 万，25 级 1800 万，30 级 5000 万。

被打回的：「熔炉 20 级」配「战力 2000 万」；熔炉 50 级、战力 9900 万；0 氪三天战力一个亿（会被玩家投诉）。星广旧表「0 氪 3 天 200 万、7 天 400 万」作废。

D2 福利（必改）。只用这四种说法，不加码：第二天签到就送传说英雄茉莉（不说 SSR 英雄茉莉）；首充就送娜塔莉亚；登录就送史诗英雄巴希提；首次抽卡必出史诗英雄谢尔盖。被拒过：「上线就送2个SSR」。英雄等级、品质、国服还没出的英雄对着查：wiki N1Kgwu6rAikCzTkULFgcYvKenXU（福利设定）、WL2YwbuBjiZZVFkxSUEcUXlmnkf（英雄系统汇总）。〔主〕〔星〕

D3 玩家人数（必改）。全球 3 亿，不说成 1 亿。别的人数、用户数说法不写。〔主〕低级问题表、〔群〕2026-01-09 起对外口径 3 亿、〔用〕。字节约 2026-02 拒过「三亿人都在玩」（缺数据证明，已交证明只到注册一亿），投字节被拒时找投放补证明，口径不改。

D4 世界观（必改）。AI 世界观不出现游戏里没有的副本，设定和等级对得上：火晶 30 级才解锁（写成 25 级是错的）；「恐龙乐园 120 级可进入」是错例。功能数值查不到就取保守值并问策划（可载人数被改成 32）。〔主〕〔群〕

D5 货不对版（必改）。文案说「广告里啥样，游戏就啥样」的，B 面必须是游戏里真有或讲得通的。传送带提效可以，石油、金币这种游戏里没有对应元素的不做。〔主〕

## E 按素材类型

E1 3D 玩法：只用本项目资产（不跨项目用创意资产，MCC 平台资产要给本项目定制，新增 2D 资产单独做）；保留冰雪元素，改尺寸后看冰雪氛围有没有被裁弱；打熊打怪不见红；不新加枪炮军武、不做军事形象；别做成捕鱼机的样子（炮台对着鱼群打、鱼身上标倍数、打中就爆金币，会按 A6 从严判，这条是按巨量赌博条款推的，审核没直接说过）；角色别穿得暴露。〔主〕〔字〕〔巨〕

E2 解说和迭代：引用的玩法片段也加提示语；评论区和对话框截图头像不用真人和卡通形象、不能有烟草，昵称打码，旁边不加手指图标；做混剪先对 A1。〔主〕

E3 真人实拍：擦边一律不做；友商常用低俗演员不用（主文档有 5 张图）；拍工作人员只能拍玩家误会了他们后来发现自己错了，不用恶意刻板印象；不挑男女对立；不蹭不良热点；粗口不出现；BGM 见 A1。巨量还会拒两类剧情〔巨〕：

- 虚假情景演绎：拿弱势群体悲情营销、下跪送锦旗、违反常理的赌誓、证件担保、冒充权威身份、过去和现在的生活对比、砸钱撒钱撕钱、维权调解、仿官方通告、打假投诉卸载、夸大灾害、考验人性
- 违背主流价值观：上班摸鱼、「性别 + 任你选」、性别歧视、伪娘和男扮女装、未婚先孕、啃老、大胃王、摆烂躺平、不孝、违法行为、拜金炫富

E4 AI 类：世界观见 D4；车标、车头格栅像真品牌判侵权；卡通形象的脸别像现成 IP（卡通牛头脸改到不像「牛来」才过）。〔主〕〔群〕

E5 明星：头衔按合同。Tim 是品牌推荐官；范明、姜超、刘奕君是明星推荐官、明星玩家；小沈阳、李乃文是代言人。名字不用字母缩写（LNW666 被拒）。用到明星的，投前跟投放确认授权材料在账户里。〔星〕〔字〕
